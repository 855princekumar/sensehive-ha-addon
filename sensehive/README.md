# SenseHive

![Supports amd64 Architecture][amd64-shield]
![Supports aarch64 Architecture][aarch64-shield]

Lightweight MQTT topic logger and dashboard for Home Assistant.

- Logs every message on the topics you add, 24/7, to SQLite
- Live dashboard with history, CSV export, tags, node grouping and LWT-based device status
- Connects to the Mosquitto broker add-on automatically
- Opens in the Home Assistant sidebar (Ingress)

See the **Documentation** tab for setup and options.
